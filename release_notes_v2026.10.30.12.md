# AutoCommand III — v2026.10.30.12

The Shields Up light look is now the app's default.

## What changed

- **Light (the Shields Up look) is the default theme.** v2026.10.30.10 shipped it as the Light option while Dark remained the default — so launching the app still showed Dark. Now a fresh install starts in the Shields Up look, and existing installs adopt it once on next launch (their registry said "Dark" only because the old default wrote it there, never because it was chosen). Prefer the operator Dark? Settings → theme switches live, and the choice sticks permanently — the one-time adoption never runs again.

No other changes from v2026.10.30.11.
